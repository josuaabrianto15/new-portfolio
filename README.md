# Portfolio - Josua Abrianto Harianja

Modern, editorial-style portfolio website built with React, TypeScript, and Tailwind CSS.

## 🎨 Design Philosophy

**Theme**: "From Ideas to Digital Experiences"

**Art Direction**: Editorial Grid - Bold typography, bento-style layouts, strong visual hierarchy, and attention to detail.

**Color Palette**:
- Background: `#0F0F0F` (charcoal black)
- Text: `#FAFAF9` (stone white)
- Accent: `#EF4444` (vibrant red)
- Highlight: `#F59E0B` (amber)

**Typography**:
- Display: Space Grotesk
- Body: Manrope
- Mono: Fira Code

## 🚀 Features

- ✨ Smooth animations with Framer Motion
- 🎯 Custom cursor (desktop only)
- 📱 Fully responsive design
- ♿ Accessibility-first approach
- 🎭 Reduced motion support
- 🎨 3D accent object with Three.js
- 📊 Scroll progress indicator
- 🎬 Section-based layout with smooth navigation

## �️ Tech Stack

- **Framework**: React 18
- **Language**: TypeScript
- **Styling**: Tailwind CSS
- **Animation**: Framer Motion
- **3D**: Three.js + React Three Fiber
- **Build Tool**: Vite
- **Package Manager**: npm

## 📦 Installation

```bash
# Install dependencies
npm install

# Run development server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```

## 📂 Project Structure

```
src/
├── components/       # Reusable components
│   ├── Navbar.tsx
│   ├── CustomCursor.tsx
│   ├── ScrollProgress.tsx
│   └── AbstractShape.tsx

│   ├── Hero.tsx

│   ├── Capabilities.tsx
│   ├── Projects.tsx
│   └── Contact.tsx
├── App.tsx          # Main app component
├── main.tsx         # Entry point
└── index.css        # Global styles
```

## 🎯 Sections

1. **Hero**: Bold introduction with animated typography and 3D accent
2. **About**: Bento-grid layout showcasing personal info and quick facts
3. **Capabilities**: Three-column breakdown of skills (Create, Build, Improve)
4. **Projects**: Featured work with varied layouts and detailed case studies
5. **Contact**: Call-to-action with social links and contact form
